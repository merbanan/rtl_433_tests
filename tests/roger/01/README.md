# Roger samples

Flipper Zero transmissions (Roger protocol) with made-up codes, recorded with an RTL-SDR at
433.92 MHz, 250 kHz, RSSI about -10 dB, SNR 28-30 dB. `protocol` loads `conf/Roger.conf`.

| File | Serial | Button | End code |
|---|---|---|---|
| `button_1_433.92M_250k.cu8` | `3C71` | 1 | `01` |
| `button_2_433.92M_250k.cu8` | `3C71` | 2 | `02` |
| `end_23_433.92M_250k.cu8` | `9E2B` | 2 | `23` |
