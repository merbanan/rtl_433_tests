# ThermoPro TX-7B outdoor thermometer hygrometer

915 MHz GFSK, decoder `thermopro_tx7b.c` (protocol 278).

Samples from https://github.com/merbanan/rtl_433/issues/3306, captured at
915 MHz and 1000k. Only part of the captures in that issue decode, these are
a selection of the ones that do with the default pulse detection, covering
channels 1-3, four sensor ids and a low battery reading. See also
https://github.com/merbanan/rtl_433/issues/3499.
