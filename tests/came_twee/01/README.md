# CAME TWEE sample

Flipper Zero transmission (CAME TWEE protocol) with a made-up code, recorded with an RTL-SDR at
433.92 MHz, 250 kHz, RSSI about -9 dB, SNR about 29 dB. One button press, all 15 messages
(counter 14 to 0). `protocol` selects the CAME TWEE decoder.

| File | DIP switches | id | button |
|---|---|---|---|
| `button_433.92M_250k.cu8` | `0111001101` | 461 | 0 |
