# iDo 117/111 samples

Flipper Zero RAW transmissions (iDo 117/111 message format) with made-up serials and random hop
codes, recorded with an RTL-SDR at 433.92 MHz, 250 kHz, RSSI about -6 dB, SNR 34-36 dB. Eight
messages per file, each with a new hop code. `protocol` enables the iDo decoder (disabled by
default).

| File | Serial (id) | Button | Hop of the first message (encrypted) |
|---|---|---|---|
| `ido_1a2b3_btn1_433.92M_250k.cu8` | `1A2B3` | 1 | `424E61` |
| `ido_fedcb_btn8_433.92M_250k.cu8` | `FEDCB` | 8 | `4B6EA0` |
