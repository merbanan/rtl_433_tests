# Elplast samples

Flipper Zero transmissions (Elplast protocol, e.g. P-11B, 3BK, E.C.A remotes) with made-up codes,
recorded with an RTL-SDR at 433.92 MHz, 250 kHz, RSSI about -7 dB, SNR 31-35 dB. Four repeats per
file. `protocol` loads `conf/Elplast.conf`.

| File | Code |
|---|---|
| `elplast_1a5c6_433.92M_250k.cu8` | `1A5C6` |
| `elplast_2b3d4_433.92M_250k.cu8` | `2B3D4` |
| `elplast_3ffff_433.92M_250k.cu8` | `3FFFF` |
