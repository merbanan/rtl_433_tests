# King Gates Stylo 4k samples

Flipper Zero transmissions (King Gates Stylo4k protocol) with made-up serials and random hop codes,
sent as RAW (no manufacturer key, no counter), recorded with an RTL-SDR at 433.92 MHz, 250 kHz,
RSSI about -12 dB, SNR 18-26 dB. Four messages per file. The decoder is enabled by default.

| File | Serial (id) | Button | Hop (encrypted) |
|---|---|---|---|
| `stylo4k_1a2b3c4d_btn_e_433.92M_250k.cu8` | `1A2B3C4D` | `e` | `CC92D33D` |
| `stylo4k_deadbe01_btn_7_433.92M_250k.cu8` | `DEADBE01` | `7` | `32833106` |
