# Nero Sketch samples

Flipper Zero RAW transmissions (Nero Sketch message format) with made-up codes, recorded with an
RTL-SDR at 433.92 MHz, 250 kHz, RSSI about -6.5 dB. Three messages per file. `protocol` enables
the Nero Sketch decoder (disabled by default).
